# Steam Controller Haptic Music & Launch Integration

A cross-platform toolkit to transform the Steam Controller into a polyphonic music player for boot-up sequences, game launches, and haptic testing on **SteamOS / Linux** and **Windows**.

## Features & Structure
- **Cross-Platform Support:** Automated launch pipelines for native Linux/SteamOS shells and Windows C# binaries.
- **Emergency Kill-Switch:** Cancel haptic tracks instantly via physical button inputs.
- For a complete setup guide, directory layout, compilation steps, and configuration details for both Windows and Linux, please refer to the repository and documentation at {Link: GitHub Repository https://github.com/mmarkus13/SteamMachine/tree/main/Controller}.
